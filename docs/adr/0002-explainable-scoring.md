# ADR 0002：情报排序用可解释规则打分，不用向量相似度

- 状态：已采纳
- 日期：2026-10-29

## 背景

聚合器通常用 embedding 召回 + 余弦相似度排序。但本产品的用户要看的是"这条为什么重要"，
而且领域词表是**专业且稳定**的（投机解码 / KV cache / PD 分离 / 异构 GPU-NPU / MoE）。

## 决策

用纯函数规则打分（0–100），输出 `scoreReasons` 明细：

1. `keyword`：标题命中权重是摘要的 3 倍（标题决定要不要点开）；
2. `source`：源自带 `weight`（0.1–3），关键词订阅 > 分类列表 > 泛科技源；
3. `recency`：7 天内缓慢衰减，30 天以上快速衰减；
4. `signal`：`release` 类型 +8（工程已验证的信号比论文更接近能落地的专利点）；
5. `penalty`：融资/体育/人事等噪音词减分。

## 后果

- 排序可解释、可调参、可单测（`score.test.ts` 断言单调性）。
- 代价：对"语义相近但用词不同"的新概念召回弱。缓解手段是可插拔关键词表 + 后续可选叠加 embedding（见 Roadmap）。
- 不引入向量库，部署只需要一个 sqlite 文件。
